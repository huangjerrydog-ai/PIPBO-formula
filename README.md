# PIPBO-fomula · 光敏材料研发管理

根据《光敏PSPI与PBO合成及配方管理系统_软件开发文档》SDD v1.1补充要求实现的 **v0.5 本机可运行版**。项目名称沿用PyCharm当前目录PIPBO-fomula。本版先实现合成—质检—配方—测试的闭环，完整企业部署功能见下方差异说明。

## 在PyCharm中运行

1. 打开本项目，选择项目的`.venv`解释器。
2. 依赖已安装。换电脑时，使用Python 3.12及以上，在项目终端执行 `python -m pip install -r requirements.txt`。
3. 右键`main.py`，选择运行。浏览器自动打开 http://127.0.0.1:8775/ 。也可运行 `python main.py --no-browser` 后手动打开此地址。
4. 首次启动创建研发管理员（用户名自行设置，密码至少10位），没有默认账号或密码。
5. 停止服务：点击PyCharm运行窗口的红色停止按钮。

服务只绑定本机127.0.0.1，不能直接供局域网其他电脑使用。端口冲突可运行 `python main.py --port 8777`。既有DA-formula程序不受影响。

## 使用流程

- **原料主数据**：内置文档69项参考物料，保留PGMEA、HEA与旧版RG-01，共72项。支持检索和新增物料。名称、CAS、供应商、牌号等身份字段以AES-256-GCM加密存储。分子量、路线等计算规格不覆盖；名称可编辑，规格变化请建新编码。
- **聚合物合成**：选择负性PSPI（PAA/PAE）或正性PBO（PHA），添加单体、封端剂、实际投料与纯度；预览nA、nB、r、Xn、封端需求、理论树脂质量、接枝投料和DAR盐额外碱需求。建立批次后进入合成中。
- **批次与质检**：合成中→提交质检→录入QC并放行。填写实测固含、GPC Mn/Mw、粘度、水分、原液/粉末形态、实际库存、有效期及携带溶剂组成。支持多种携带溶剂，比例合计100%。PDI按Mw/Mn计算。放行QC不可覆盖。支持隔离；隔离后不能新配胶。
- **光敏胶配方**：选择同路线且已放行、未过期、有库存的树脂批次，可按干树脂占比混批。输入干树脂质量、助剂phr、助剂有效固含与载体溶剂、目标固含及最终全部溶剂配比。预览实际称量及wt%，再保存并原子扣减库存。比例错误、库存不足、跨路线光敏剂、目标固含无法靠稀释达到、溶剂负称量均会被后端阻止。
- **配方与追溯**：查看配方与来源树脂批次、使用时SC/QC快照、称量与备注，下载CSV称量单。已保存配方不允许覆盖，调整后建立新记录。
- **光刻测试**：关联配方批号，记录膜厚、曝光剂量、分辨率、残膜率、固化温度、粘度及实验条件。
- **账户与审计**：管理员可创建实验室账户。实验室账户仅查看内部编码、批次QC、配方称量与测试指标，不能读取真实物料身份或管理员备注，不能创建合成、放行、扣减库存或查看审计。审计记录登录、身份库查看、建批、放行、隔离、配方保存与测试录入。会话8小时到期。

## 批量导入（v0.2）

原料导入入口：**原料主数据 → 批量导入原料**。测试数据入口：**光刻测试 → 批量导入测试数据**。

1. 在导入窗口下载Excel或CSV模板，按列名填写。Excel模板的“填写说明”表提供字段、单位与类别规则。
2. 选择文件，点击“上传并预览”。支持.xlsx、UTF-8/GB18030的.csv和.tsv；旧版.xls须另存为.xlsx。每批最多1000条数据、5MB，空白记录忽略；单文件扫描上限20000行。
3. 核对“待导入、重复跳过、错误记录”与逐行预览。可以横向滚动查看所有字段。有错误时整批不保存，可下载CSV错误报告，修正源文件后重新上传。
4. 预览通过后，点击“确认导入”。预览30分钟内有效，仅上传文件的账户能确认。提交前再次校验，所有新增记录同一事务保存，重复点击不会重复写入。

**原料字段**：内部编码、物料名称、类别、适用路线、分子量必填；CAS、供应商、商品牌号、SMILES选填。类别与路线沿用单条录入校验。已有编码跳过整行，不比较或覆盖其原值；要变更规格请建立新编码。文件内重复编码视为错误。SMILES仅保存文本，不代表结构已验证。

**测试字段**：外部记录ID、配方批号必填；膜厚、曝光剂量、分辨率、残膜率、固化温度、粘度至少填写一项，备注选填。配方批号须已存在，可从“配方与追溯”查找。外部记录ID建议使用实验室编号加流水号，作为全系统唯一标识。相同ID且内容一致会跳过；相同ID但内容不同会报错，不覆盖既有记录。测试历史显示外部记录ID，手工录入显示手动记录编号。

**数值与单位**：空白表示未测，0为实际测量值。残膜率填写普通数字95表示95%，不能把Excel百分数单元格0.95/95%直接混入。膜厚与分辨率为μm，曝光剂量为mJ/cm²，固化温度为°C，粘度为mPa·s；导入不进行单位推断或换算。不接受公式或Excel错误单元格，请粘贴为数值。

Excel仅读取名为“数据”的工作表，否则读取第一张表；多工作表文件会在预览中提示其余表未导入。表头支持模板中文列名或对应英文键，未知列、重复映射列会被拒绝，避免静默丢列。

原料导入与模板仅研发管理员可用；测试数据导入沿用管理员/实验室账户权限。原料真实身份字段继续加密存储，导入暂存内容也加密保存；上传原文件不保存到服务端。预览和确认均记录审计，审计不记录物料真实名称及文件内容。测试导入不影响树脂库存。

## 中文名、过量比与PSPI分步合成（v0.3）

### 中文名称

物料库、合成单体、侧链试剂及配方菜单均同时显示内部编码、中文名和英文简称，支持中文搜索。内置物料自动补充中文名；识别到旧自定义物料的名称已经含中文时，将其补充到中文名字段；无法确定的旧英文物料显示“待补充中文名”，可在“原料主数据→编辑名称”维护。名称与供应商/CAS同样加密保存，实验室权限不返回真实名称。编辑名称不改内部编码、分子量、已保存批次的称量和计算结果。

原料批量导入模板增加“中文名称”列，兼容无此列的旧模板；模板中类别RG表示工艺试剂。保留原料已有编码整行跳过的规则；要补充已有物料中文名，请使用“编辑名称”。

### 过量方与目标投料

在“聚合物合成”中，A为二酐/二酰氯，B为二胺/双邻氨基苯酚：

- 按实际投料：保持录入的称量，计算实际过量方和过量百分比。
- A:B等摩尔：保持A投料，按纯度修正后的摩尔数计算B投料。
- A过量e%：保持B投料，调整A，使nA/nB=1+e/100。
- B过量e%：保持A投料，调整B，使nB/nA=1+e/100。

选择目标后点击“按比例调整投料”才修改输入框；同一组混合单体按相同比例缩放，保留组内质量/摩尔配比与纯度，封端剂不随之缩放。再点击“计算并预览”核对称量。目标与实际投料不一致时，后端会阻止建立批次。过量值0–100%，例如5%表示比值1.05。封端需求按B过量估算；A过量时当前酸酐型封端剂不用于酸端封端，需另行确认合适封端体系。

### PSPI三种可选路径

1. **PAA直接聚加**：二酐与二胺直接反应，无侧链预酯化。
2. **PAA聚合后接枝**：支持HEMA、HEA、GMA、MOI，沿用2nAα简化位点模型；不同实际位点和反应活性需研发确认。
3. **PAE预酯化→酰氯化→缩聚**：按用户所述先引入羟基型光敏侧链，再以二氯亚砜活化羧基，最后与二胺形成PAE。HEMA提供甲基丙烯酸酯侧链，HEA作为同类单羟基试剂的计量扩展提供丙烯酸酯侧链。GMA/MOI不适用同一预酯化模型，程序会阻止混用。

分步路线记录：

- 第一阶段：每摩尔二酐按2摩尔HEMA/HEA引入侧链，可填写试剂过量%、纯度或实际称量；记录预酯化备注。
- 第二阶段：每摩尔二酐生成2摩尔羧基，按SOCl₂/COOH当量、有效纯度计算二氯亚砜称量；可填写实际称量及阶段备注。
- 第三阶段：继承二胺、封端剂及A/B过量比，计算缩聚质量变化并记录备注。

实际侧链试剂/二氯亚砜称量填写后，优先使用实际值并显示实际过量/当量；目标值仅用于空白时的建议称量。完全二酯化/完全酰氯化模型要求有效试剂至少达到理论当量，少于理论值会被拒绝。本版不使用同一模型预测部分酯化混合体系，α固定为1；也不推断实验温度、反应时间、转化率与真实工艺收率。

### 分步路线质量模型与来源

设二酐为a mol、二胺为b mol，H为HEMA/HEA分子量：

- 侧链计入骨架的量为2a mol；二酐开环预酯化不扣水，二酯二酸质量为有效二酐质量+2aH。
- SOCl₂理论消耗2a mol，酰氯化生成2a mol SO₂及2a mol HCl。使用SOCl₂ 118.96、SO₂ 64.06、HCl 36.46 g/mol，故中间体每摩尔羧基净增18.44g。
- 缩聚按限制双官能单体完全反应，扣除2min(a,b)×36.46g HCl；封端剂有效质量沿用单独相加的前体近似，未计后续热环化。
- 过量HEMA/HEA、SOCl₂、杂质不作为树脂骨架质量。未计算捕酸剂、盐、未反应单体分离和损耗。p只用于Carothers Xn估算，阶段质量及副产物以完全反应为假设，不能替代实测SC和GPC。

核对例：0.1mol PMDA（21.812g）、0.1mol ODA（20.024g）、0.2mol HEMA（26.028g）和0.2mol SOCl₂（23.792g）；二酯二酸47.840g、二酯二酰氯51.528g，PAE理论64.260g，总HCl14.584g、SO₂12.812g。纯反应物质量=理论产物+理论气体副产物。此例仅用于程序计算校验，不是实验操作配方。

依据与数据来源：[US6773866B2](https://patents.google.com/patent/US6773866B2/en)中的二酐—醇—二酰氯—二胺路线；[TCI HEA A0743](https://www.tcichemicals.com/OP/en/p/A0743)（CAS818-61-1，116.12）；[TCI SOCl₂ T2040](https://www.tcichemicals.com/JP/en/p/T2040)（CAS7719-09-7，118.96）。商品有效含量须按实际批次CoA录入。

已保存批次保留路径、侧链选择、目标和实际过量、三阶段投料与备注。旧批次的计算快照保持原值，旧的未指定路径接枝请求仍按旧后接枝模型处理。

## 计算说明与文档纠错

文档把 `nA/(nB+nE)` 和 `nA/(2nB−nA)` 写成等式，同时规定 `nE=2(nB−nA)`；代入后前者分母实际是`3nB−2nA`，二者不相等。本版不据此给出封端后精确Mn，而把双官能聚合度估算和封端需求分开：

- `r=min(nA,nB)/max(nA,nB)`；`Xn=(1+r)/(1+r−2rp)`，p是限制反应基团的转化率；r=p=1时显示趋于无穷，不返回非法JSON数值。
- 胺/双邻氨基苯酚过量时，单官能封端需求为`2 max(nB−nA,0)`，不表示已完成封端。实测GPC Mn/Mw单独录入。
- DAR·2HCl按摩尔质量213.06计算物质的量，链段质量用140.14，额外碱需求为2.05倍DAR摩尔数。
- PBO完全反应干质量参考扣除`2 min(nA,nB) × 36.46`的HCl。树脂质量估算未计未反应组分的分离、实际收率、盐与工艺损耗，最终称量始终使用实测批次SC。PAA后接枝按文档2nAα模型；HEMA/HEA按18.02净质量扣除，GMA/MOI按无离去质量估算；PAE预酯化阶段不扣水，按上方v0.3分步模型计算。实际机理与位点需研发确认。本版不计算可溶性PI的热环化质量变化。
- 标准双官能估算与其假设可参考原始研究：[De Keer et al., Polymers 2021, 13, 2410, Eq. (5)](https://www.mdpi.com/2073-4360/13/15/2410)。该模型忽略分子内环化和不同反应活性，不能作为实测分子量替代。
- 物料CAS/MW来自用户文档，未做供应商逐条独立认证。PAC-01/02的MW为母核参考，不能用于商品DNQ酯的摩尔计算。原液SC<100%时剩余质量按登记溶剂模型处理，实际含水/杂质应由研发核对。

文档示例已验证：PBO母液SC28.5%，干树脂100g；PAC18phr、AD-01 2.5phr、AD-02 0.5phr，25%总固含，最终溶剂GBL/PGMEA=80/20。成品484g，母液350.877193g，新增GBL39.522807g、PGMEA72.6g；母液850g入库后剩499.122807g。

## v0.4 / SDD v1.1 补充实现（2026-11-19）

进入“聚合物合成”默认使用多元共聚设计。A、B组分别添加多个单体，输入相对摩尔比（例如7:3）自动归一；或选择mol%模式，各组须合计100±0.01。组间r=nA/nB独立设置，当前模型支持0<r≤1，B过量时自动计算NA等封端剂。支持指定A/B总mmol，或目标理论干树脂质量反算；称量按各项纯度折算。组成标签保存在批次并可检索。r_eff和完全转化Xn单独展示，不替代按转化率p计算的双官能Carothers估算。

PAE三步法按四阶段ELN执行：开环酯化→低温酰氯化→低温缩聚及室温续反应→沉淀洗涤与真空干燥。HEMA、DBU、SOCl₂、Py、HQ1按nA联动计算，支持HEMA/HEA；HQ2、NMP1、NMP2须明确填写本批次计划量，系统不推测文档未给出的用量。Py留空按最低有效需求配平；PBO的DAR盐仍按213.06称料、140.14计骨架，并在正常酸吸收需求外加2.05nDAR的吡啶。

建立PAE模板批次后，在“批次与质检→工艺打卡”依次填写开始和完成记录。系统检查氮气、尾气吸收、冰水浴、滴加方式、0–10°C低温范围、阶段保温时长、室温续反应、洗涤次数及体积、40–60°C真空干燥至少24h。完成记录冻结；四阶段及纯化记录完整后自动进入待质检。记录为人工填写的实验实际数据，无实时仪器连接，也不依据程序运行时间冒充实际保温时间。

Stage 4填写实际分离干粉质量，自动计算分离收率；质检按实测固含填写，限定DRY_POWDER入库，库存不得超过实际干粉质量。放行后沿用现有配胶质量平衡与库存扣减。旧版批次保持原快照及原流程，不补造阶段记录；旧版自定义称量入口仍可使用。

新增IN-03(HQ)、CAT-01(DBU)、CL-01(SOCl₂)、AS-01(Py)、WP-01(EtOH)，共69项文档物料加3项历史/扩展物料。旧RG-01的118.96历史规格保持不变，新模板使用CL-01的118.97。文档a-BPDA/ODA/2HEMA示例写718.71，按给定分子量294.22+200.24+2×130.14−2×18.02得到718.70，程序采用逐项算术结果。

数据库继续使用本机SQLite；新增摩尔投料、四阶段、纯化记录关系表、外键、CHECK和状态触发器，未迁移到文档建议的PostgreSQL 16企业架构。材料密文、既有账户和业务数据沿用原data目录。升级前备份整个data目录（数据库及密钥须一起保留）；不要把data、密钥或测试账户上传GitHub。源码包不含任何业务数据或密钥。

验证：24项自动测试通过，覆盖旧配方/库存/权限/导入及新摩尔配料、目标干重反算、DAR补碱、工艺顺序/温度/时长/洗涤、不可覆盖记录及QC放行限制；浏览器使用独立测试数据库操作新页面。

## 按阶段选择可变助剂

“PAE四阶段·工艺助剂联动”已分成四张阶段卡片，每个阶段都有“＋助剂”。DBU、HQ、Py以可编辑行预填，可移除、改选原料和新增其他CAT/AS/IN/AD/WP类助剂。各行独立选择实称质量g、相对二酐eq/mol%、相对侧链实称质量wt%，并填写纯度；阶段3的Py另支持自动吸酸配平。HQ不再固定必须添加；同一助剂可在不同阶段分别使用，同阶段重复编码需合并。当前吸酸需求模型仅计入阶段3的AS-01(Py)，其他助剂不能自动替代其吸酸能力；不足时允许预览但阻止建批。实际实验方案由研发确认。

新批次保存各行原料、计量方式、输入用量及计算后的有效摩尔量/实称质量，并写入对应阶段计划快照。旧版批次和旧API参数保持兼容。25项自动测试通过，并用独立浏览器数据库检查助剂移除、添加、改选与保存回读。

## 反应方法管理（v0.5）

管理员登录后，左侧选择“反应方法管理→＋新建反应方法”。填写名称、PSPI/PBO路线和说明，配置1–12个步骤。每步填写名称、计划温度上下限、最低持续时长、装置/加料方式及操作要求；通过“＋原料/助剂”按物料编码预填实称质量g与纯度，也可在建批时添加。支持步骤上移、下移、移除。

方法库可检索、编辑、复制、启用/停用。每次编辑保存增加版本号，版本历史存数据库；停用后不能新建批次，既有批次不受影响。并发编辑或使用过期模板建批会被拒绝，需重新打开最新方法。

点击“生成聚合页”，自动按模板生成本批次步骤、投料及条件表单。可调整本批次称量、温度、时长与操作条件；核对投料后建立聚合批次。本版自定义方法只汇总实称总投料（含溶剂/助剂），不自动计算新反应的理论干重、当量配平或产率；需要这些自动计算时，使用页面下方已有PAE/PAA/PBO专用计算入口。自定义步骤的温度/时长规则来自研发手工设置，不自动继承PAE四阶段的专用门禁。

“批次与质检→方法步骤记录”按顺序填实际温度、时长、操作与异常记录，并确认投料、装置和操作要求。系统校验本批次计划范围和最低时长，前一步未完成时不能跳步；已完成记录不可覆盖。全部完成自动进入待质检，再录入实测QC及实际入库量；后续配方称量、库存和追溯沿用原流程。系统不读取仪器，也不将页面停留时间当作实验持续时间。

方法模板、版本、批次步骤分别建表；建批保留模板版本及完整计划快照，修改模板不会改变历史批次。实验室账户不能管理方法或读取工艺明细，管理员操作记入审计。测试使用独立数据目录：27项自动测试通过，覆盖原功能及方法版本冲突、停用、路线限制、快照、禁止跳步、温度/时长限制、QC门禁、完成记录冻结和权限；浏览器验证新建方法→生成聚合页→称量核对→建批→步骤完成→待质检。
